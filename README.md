## Reproduction scope

The submission reproduces the three outputs specified in the project plan:

1. AVG, CARRY, and CMOM return series and summary statistics.
2. Pricing errors and cross-sectional R-squared values for one-, two-, and
   three-factor models, including Table 3 and Figure 2.
3. The relation between rank Carry and innovations in global equity volatility,
   including the Table 8 time-series and cross-sectional exercises.

Carry is constructed by ranking the monthly slope cross-section, going long the
bottom five and short the top five. The exported results label this rule as
`unconditional_rank_bottom_top_5`. Raw WRDS data, credentials, and the authors'
reference file are not committed.

## Installation

From the repository root:

```bash
# Use Python 3.10 through 3.13.
python -m venv .venv
python -m pip install -e ".[dev]"
```

The default run asks for a WRDS username and password when no matching standard
libpq password-file entry (`~/.pgpass` or `PGPASSFILE`) is available. The
password is not echoed or stored. Credentials must never be committed to the
repository.

## One-command reproduction

For a complete run, including acquisition when a raw snapshot is missing:

```bash
python run_all.py
```

For a repeat run using only cached raw snapshots:

```bash
python run_all.py --offline
```

To rebuild only Phase 1 results from existing raw snapshots:

```bash
python run_all.py --results-only --offline
```

The equivalent thin scripts are ordered under `scripts/`. The notebooks are
for transparent inspection and exploration; reported results are generated by
the importable code under `src/project/`.

## Main findings

The rank-C5 balanced asset-pricing sample contains 427 months. The three-factor
model has OLS and GLS cross-sectional R-squared values of 91.91% and 98.42%,
and is not rejected by the Newey-West, Shanken, or two-step GMM pricing-error
tests. Figure 2 annualized MAE is 1.80%, compared with 1.84% in the paper.

Carry loads negatively on innovations in the 19-country global equity-
volatility proxy. The relation is concentrated in the long/backwardated leg,
and the equity-volatility innovation receives a negative price of risk in the
cross section of P1-P4.

## Limitations

The reconstruction uses WRDS rather than the authors' CME files. Original
Propane is unavailable, early country-index coverage is thin, federal holidays
proxy for exchange calendars in fallback notice conventions, and the G20
equity-volatility series uses representative local indexes rather than the
authors' original series. These limitations and all nonmatches are documented
in `report/data_methodology.md`, `report/asset_pricing_replication.md`, and
`report/equity_volatility_replication.md`.
